\textbf{Overview.} This supplementary material provides four sections in
support of the main manuscript:

\begin{itemize}
    \item \textbf{S1} addresses the sensitivity of the U-shape detection
    to the choice of environmental proxy radius and definition.
    \item \textbf{S2} presents a formal model comparison among five
    competing functional forms.
    \item \textbf{S3} provides a covariate-controlled test of the sign
    inversion in TNG300, explicitly stratifying by an environmental
    indicator.
    \item \textbf{S4} presents a multivariate regression analysis of the
    TNG100-1 catalogue in which environment is treated as the primary
    independent variable and gas fraction and stellar mass are demoted to
    statistical controls.
\end{itemize}

All analyses are reproducible using the scripts archived on Zenodo
(DOI:~10.5281/zenodo.17806442) and on the GitHub repository
\url{https://github.com/JonathanSlama/QO-R-JEDSLAMA}.
